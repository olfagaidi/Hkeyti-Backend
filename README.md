# ❤️ Hkeyti – Plateforme de Signalement et d’Accompagnement Social & Santé

**Hkeyti** est une plateforme web dédiée à l’écoute, au signalement et à l’accompagnement des personnes confrontées à des problèmes sociaux, familiaux ou de santé. Le projet vise à faciliter la communication entre les citoyens et les professionnels (psychologues, assistants sociaux, médecins...) de manière confidentielle, structurée et sécurisée.

---

## 🌐 Objectifs de la plateforme

- 📝 Permettre aux utilisateurs de **partager leur histoire** (signalement anonyme ou identifié)
- 💬 Faciliter le **dialogue avec des spécialistes** via une messagerie privée
- 🧑‍⚕️ Gestion des intervenants : psychologues, médecins, travailleurs sociaux
- 📊 Suivi des cas avec historique et recommandations
- 📂 Téléversement sécurisé de documents médicaux ou justificatifs
- 🔐 Sécurité et confidentialité des données utilisateur

---

## 🛠️ Technologies utilisées

| Composant     | Technologie             |
|---------------|--------------------------|
| **Frontend**  | Angular, TypeScript, Bootstrap |
| **Backend**   | PHP 8 (Laravel ), REST API |
| **Base de données** | MySQL ou PostgreSQL       |
| **Sécurité**  | Auth JWT, rôles utilisateurs (Admin, Utilisateur, Intervenant) |
| **Déploiement** | XAMPP / Docker (facultatif) |
